# ICSE Kids App 🎓

**Interactive Learning App for Nursery, LKG & UKG (ICSE Board)**  
Built with Flutter • Advanced Animations • Voice Commands

---

## ✨ Features

- **Class Selection**: Nursery, LKG, UKG
- **Subjects**:
  - Alphabet
  - Numbers
  - Phonics
  - Shapes & Colours
  - Rhymes & Stories
- **Advanced Animations** using Rive & Lottie
- **Voice Commands** (Speech-to-Text)
- **Text-to-Speech** for lessons and feedback
- Progress tracking with stars
- Beautiful, child-friendly UI
- Offline support for core lessons

---

## 🛠️ Tech Stack

| Feature              | Technology              |
|----------------------|-------------------------|
| Framework            | Flutter                 |
| Animations           | Rive + Lottie           |
| Voice Input          | speech_to_text          |
| Voice Output         | flutter_tts             |
| State Management     | Provider                |
| Local Storage        | Shared Preferences      |

## 🚀 Getting Started

### Prerequisites
- Flutter SDK (3.16 or higher)
- Android Studio / VS Code
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/icse-kids-app.git

# Go into the project
cd icse-kids-app

# Install dependencies
flutter pub get

# Run the app
flutter run
